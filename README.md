# WeEngage - AI-Powered Hospitality Platform

WeEngage is a next-generation hospitality platform designed to transform guest experiences in independent properties through AI-powered solutions. The platform helps small hotels, B&Bs, and homestays deliver exceptional service while optimizing operations and increasing revenue.

## 🚀 Features

WeEngage offers a comprehensive suite of tools for modern hospitality:

- **GuestHub**: Digital concierge with AI-powered check-in, communications, and service recommendations
- **ATLAS**: Complete Property Management System for front office, housekeeping, and maintenance operations
- **LOOP**: Guest engagement suite with loyalty programs and automated feedback collection
- **PRISM**: Smart pricing and analytics platform with revenue intelligence

## 📋 Project Structure

```
app/               # Main application routes and pages
    (products)/      # Product-specific pages (atlas, guesthub, loop, prism)
    blogs/           # Blog pages with dynamic content
components/        # UI Components
    shared/          # Shared components used across multiple pages
    ui/              # Base UI components (buttons, cards, inputs, etc.)
lib/               # Utility functions and helpers
```

## 🛠️ Technologies

- **Next.js**: React framework for server-rendered applications
- **TypeScript**: Type-safe JavaScript
- **Tailwind CSS**: Utility-first CSS framework
- **Shadcn UI**: Unstyled, accessible component primitives
- **Lucide Icons**: Beautiful, consistent icon set

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
     ```bash
     git clone https://github.com/yourusername/weengage-landing.git
     cd weengage-landing
     ```

2. Install dependencies
     ```bash
     npm install
     # or
     yarn install
     ```

3. Start the development server
     ```bash
     npm run dev
     # or
     yarn dev
     ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🧪 Building for Production

```bash
npm run build
# or
yarn build
```

To start the production server:
```bash
npm start
# or
yarn start
```
